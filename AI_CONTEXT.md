# OmniShelf: B2B Smart Expiry & Inventory Management Platform
- **Target Audience**: Small Businesses, Mini-Warehouses, Grocery & Perishable Retailers
- **Primary Goal**: Minimize food/perishable spoilage via FEFO inventory sorting and automated OCR expiration extraction.
- **Frontend**: Flutter Mobile App (Camera Barcode + Image Upload)
- **Backend / Cloud**: AWS Lambda (Python 3.11), API Gateway, DynamoDB, Amazon SNS
- **AI / OCR Layer**: AWS Textract (Label OCR) + Amazon Bedrock (Expiry & Batch Extraction)
- **Hardware**: None (Pure smartphone camera capture)
